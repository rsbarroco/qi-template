# SHOP-100 — Epic: Promotions

**Type:** Epic
**Status:** In progress

## Description

Everything related to promotional pricing for Q3: coupon codes, automatic discounts and
promo banners.

## Scope notes

- Coupons apply to the subtotal only; shipping is never discounted.
- All promotion errors use the inline error component (red banner above the input).

## Children

- SHOP-101 — Coupon code applies a percentage discount at checkout
- SHOP-104 — Coupon analytics event
- SHOP-110 — Automatic bundle discount (not started)
