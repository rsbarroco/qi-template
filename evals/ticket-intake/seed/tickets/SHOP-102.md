# SHOP-102 — Remove item from cart

**Sprint:** 26-09
**Type:** Story

## Description

A customer can remove an item from the cart using the trash icon on the cart row.

## Acceptance criteria

- AC1: Clicking the trash icon on a cart row removes that item and the cart total is
  recalculated.
- AC2: Removing the last item shows the empty-cart message "Your cart is empty".

## Validation steps

Dev environment, cart page `/cart`.
